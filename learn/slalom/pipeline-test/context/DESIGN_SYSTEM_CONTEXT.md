# Design system context: Slalom design system review

> Load this as a system prompt, a skill or a rules file when generating UI code. Generated by Lockstep on 2026-10-22 from the items people approved in review. Anything not listed here isn't part of the system yet.

## Rules

1. Build with the components from `@slalom/design-system`. Don't use raw HTML elements or the underlying UI library directly when one of these components covers the need.
2. The stack is Vue + Vuetify.
3. Never hard-code colours, spacing, radii or shadows. Use the tokens below by their CSS name.
4. The font is Slalom Sans.
5. 15 questions are still open (listed at the end). Where your code touches one, ask instead of picking a side.
